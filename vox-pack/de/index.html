Vox-Pack

Geben Sie Ihrer Fernsteuerung eine Stimme.

Vox-Pack erzeugt die Ansagen, die Ihre EdgeTX-Fernsteuerung im Flug spricht: „Motor an“, „Fahrwerk ausgefahren“, „Timer gestartet“ … Sie wählen die Stimme, schreiben die Sätze, und die Anwendung erzeugt WAV-Dateien, fertig für die SD-Karte.

macOS Windows Kostenlos Open Source
Für macOS herunterladen Für Windows herunterladen Versionshinweise

Intel-Mac: Vox-Pack-Intel.zip · Windows portabel: Vox-Pack.exe

68 Stimmen, fünfzehn Sprachen

Vom Französischen bis zum Ukrainischen, über Japanisch und Chinesisch: 68 Stimmen in fünfzehn Sprachen, darunter die offiziellen von EdgeTX — Denise (★), Emily (★) und Katja (★).

Ein neuer Bildschirm

Gezeichnete Liste, runde Anzeige, Roboter- und HAL-Lichter, integrierte Hilfe: Die Anwendung wurde neu gestaltet, und jede Sprache behält ihre eigene Liste.

System-Ansagen von EdgeTX

Die offiziellen SYSTEM-Ansagen der gewählten Sprache (186 auf Französisch, 212 auf Englisch, 211 auf Deutsch und die der anderen Sprachen) mit der gewählten Stimme, in einem Ordner SYSTEM/, fertig für die SD-Karte.

Roboterstimmen

Drei Punkte Roboter 1 bis 3 verändern die gewählte Stimme, und HAL 9000 setzt seine eigene durch. Kein Punkt markiert: die normale Stimme.

Pausen in der Ansage

Ein „>“ im Satz erzeugt eine Pause von einer halben Sekunde, „>>“ eine ganze. So verzögern Sie eine Ansage: „>>> Motor an“.

EdgeTX-Format

WAV mit 16 Bit, 32 kHz, mono — genau das, was die Fernsteuerung erwartet. Stille an den Enden entfernt, Pegel angehoben, wie bei den offiziellen Ansagen.

Für das Erzeugen der Stimmen ist eine Internetverbindung nötig (der Dienst von Microsoft). Die erzeugten Dateien bleiben auf Ihrer SD-Karte und funktionieren offline. Die Anwendung gibt es in fünfzehn Sprachen; sie startet in der Sprache Ihres Computers.
