USB-Floss Magic

La même chose, en minimaliste.

Une interface directe pour nettoyer ta clé USB des fichiers inutiles. Un bouton, un message clair, et c'est fait.

macOS Gratuit Open source
Voir la dernière version Code source

Minimaliste

Pas de fenêtre inutile : ce qu'il faut, au bon endroit.

Nettoie ta clé

Les fichiers inutiles de macOS (.DS_Store, ._*) disparaissent de la clé.

Sans détour

Tu branches la clé, tu cliques, c'est nettoyé. Gratuit et open source.

Le fichier à télécharger se trouve sur la page Releases.

Sur macOS (Apple Silicon), avec Homebrew : brew install --cask ritchy-lab/tap/usb-floss-magic
